# MASTER PROMPT – MINI HRM SAAS
## Full-Stack HRM, Attendance & Payroll Platform
**Version:** 1.0  
**Target:** Vietnam SMB (5–30 employees)  
**Development Environment:** Windows 10, VS Code / Codex  
**Production:** Ubuntu VPS + Nginx + PHP 8.3 + MySQL 8  
**Languages:** Vietnamese UI, English code and documentation

---

# 1. ROLE & MISSION

You are a senior software architect, full-stack engineer, Android engineer, UI/UX designer, database architect, security engineer, QA engineer and DevOps specialist.

Your mission is to design, implement, test and deliver a production-oriented, multi-tenant SaaS platform named **Mini HRM**.

The system consists of:

1. SaaS Super Admin Web Portal.
2. Company Admin Web Portal.
3. Employee Android Application.
4. REST API Backend.
5. MySQL Database.
6. Attendance and Payroll Calculation Engine.
7. SaaS Subscription and Billing System.
8. Background Jobs and Notifications.
9. Automated Tests and Deployment Documentation.

**Do not deliver only mockups, pseudocode, empty pages or placeholder implementations.**

Build a functional application with real database persistence, authentication, authorization, business rules, API integration and meaningful test coverage.

When a third-party service requires credentials, implement the integration interface, configuration, safe fallback and setup instructions. Never invent credentials or claim an external integration is operational without testing it.

# 14. PAYROLL ENGINE – CRITICAL MODULE

This module must be deterministic, auditable and heavily tested.

Support:
- Monthly salary.
- Daily salary.
- Hourly salary.
- Part-time salary.
- Fixed allowances.
- Variable allowances.
- Overtime.
- Bonuses.
- Salary advances.
- Deductions.
- Unpaid leave.
- Paid leave.
- Custom payroll components.

Payroll periods:
- Monthly.
- Custom start/end dates.

Payroll workflow:

Draft → Calculate → Review → Approve → Lock → Publish Payslips.

Once locked, payroll records must not be silently modified.

Corrections require a controlled adjustment or recalculation workflow with full audit history.

## Calculation principles

Use decimal arithmetic or integer minor currency units.

Never use binary floating-point for money.

Separate:
- Gross earnings.
- Employee deductions.
- Employer costs.
- Statutory deductions.
- Advances.
- Net payable.

Store calculation inputs, policy version and detailed output components.

Provide a payroll breakdown explaining how each amount was calculated.

Example:

Basic salary: 8,000,000 VND
Allowance: 500,000 VND
Overtime: 750,000 VND
Advance: 1,000,000 VND
Other deduction: 200,000 VND

Illustrative net before statutory deductions:
8,050,000 VND.

This is a sample calculation, not a legally complete Vietnamese payroll calculation.

## Vietnam payroll compliance

Design configurable, effective-date-versioned modules for:
- Statutory overtime rules.
- Minimum wage references.
- Social insurance.
- Health insurance.
- Unemployment insurance.
- Personal income tax.
- Applicable exemptions and deductions.

Do not invent legal rates or hard-code unverified 2026 values.

Where statutory compliance has not been implemented and verified, clearly label the payroll result as a non-statutory estimate and prevent the system from presenting it as legally complete.

Create a compliance checklist and a separate legal-rules configuration layer.

Use shared database, shared schema with tenant isolation.

Every tenant-owned table must include tenant_id or have an explicitly documented, safely enforced ownership relationship.

Implement:
- Tenant context middleware.
- Tenant-scoped repositories/queries.
- Object-level authorization.
- Role and permission checks.
- Secure password hashing.
- Login rate limiting.
- Token rotation/revocation.
- CSRF protection where applicable.
- XSS protection.
- SQL injection prevention.
- Input validation.
- Secure file upload.
- Secrets management.
- Audit logging.

Never trust tenant_id supplied by the client.

Resolve tenant context from authenticated and authorized membership.

Super Admin access must be isolated and audited.

Create automated tests that attempt cross-tenant access to:
- Employees.
- Attendance.
- Timesheets.
- Payroll.
- Payslips.
- Reports.
- Files.
- Branches.

All such unauthorized requests must fail.
